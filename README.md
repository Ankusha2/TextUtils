# Text Utils ✍️🔤

**Text Utils** is a simple yet powerful text manipulation app built with **React JS** and styled with **Bootstrap**.  
It provides users with a set of handy utilities to analyze, transform, and manage text efficiently through a clean and responsive UI.  

## 🌟 Features

- **Convert to Uppercase:** Quickly transform text to uppercase.  
- **Convert to Lowercase:** Convert text to lowercase with a click.  
- **Clear Text:** Instantly clear the text input field.  
- **Remove Extra Spaces:** Clean up extra spaces between words.  
- **Word & Character Count:** Real-time statistics for words and characters.  

## 💻 Technology Stack

- **React JS:** Component-based architecture for building UI  
- **Bootstrap:** Responsive design and modern styling  

## 🎨 Highlights

- Clean and user-friendly interface  
- Responsive design  
- Real-time text processing
